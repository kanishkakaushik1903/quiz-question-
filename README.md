# Simple Quiz Form 📝

A responsive, interactive Quiz Form built using HTML, CSS, and JavaScript. This project allows users to answer a set of questions, validates their input, and provides instant feedback with a final score upon submission.

## 🌟 Features

* **Responsive Design:** Fully responsive layout with three questions, optimized for various screen sizes.
* **Instant Feedback:** Visual cues indicate correct (Green Checkmark ✅) or incorrect (Red Cross ❌) answers immediately after submission.
* **Score Calculation:** Displays a final score summary based on the user's performance.
* **Modern Styling:** Built with **Bootstrap 5.3.3** for layout and custom CSS for aesthetics.
* **Interactive UI:** Features an animated submit button with a glowing hover effect and an engaging background image.

## 🛠️ Technologies Used

* **HTML5:** Structure of the form and semantic markup.
* **CSS3:** Custom styling, Google Fonts integration, and button animations.
* **JavaScript:** Logic for form validation, answer processing, and result calculation.
* **Bootstrap 5.3.3:** Framework for responsive grid layout and components.
